# Maskly privacy notice

Maskly is designed to protect browser-based AI conversations locally.

- Original prompt values are processed by the extension in the browser.
- Placeholder mappings are encrypted with AES-GCM and stored in browser extension storage.
- Mappings expire after 30 days and can be cleared by the user.
- Maskly does not send prompt content to a Maskly server in this MVP.
- Masked request bodies are sent to the AI website selected by the user.
- If response restoration is enabled, restored response text is displayed back in the AI website page.
- The extension does not collect analytics or sell user data.

This notice should be hosted at a public HTTPS URL before store submission and linked from the store listing.
